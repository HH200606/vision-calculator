# 机器视觉选型计算器

一个零依赖的单文件网页工具，输入**视野**与**精度**要求，自动推导出所需的**工业相机规格**与**镜头焦距**。

<sub>Machine Vision Selector — pick the right camera & lens from your FOV and accuracy requirement.</sub>

---

## 在线使用

直接打开 `index.html` 即可，无需安装、无需联网、无需构建。

也可以部署到任意静态托管（GitHub Pages / Vercel / Netlify），或直接双击本地文件运行。

## 功能

### 输入参数

| 参数 | 说明 |
|---|---|
| 最大视野 FOV | 长边方向的可视范围（mm） |
| 精度要求 | 需稳定检出的最小尺寸或缺陷（mm） |
| 工作距离 WD | 镜头前端到被测物的距离（mm） |
| 安全系数 | 2× 极限 / 3× 推荐 / 4× 稳健 |
| 镜头类型 | FA 定焦镜头 / 双远心镜头 |
| 画面比例 | 4:3 / 16:9 / 1:1 |

### 输出结果

- **相机**：像素档位（500 万 ~ 6500 万）、分辨率、靶面尺寸、像元尺寸、推荐接口
- **镜头**：焦距 / 倍率、靶面支持要求、光圈、接口
- **验证指标**：实际视野、像素精度（mm/px）、可检测精度、景深估算
- **判定结论**：余量充足 / 刚好达标 / 视野受限 / 精度不足 / 像素不足
- **计算过程**：完整算式逐步展示

## 计算原理

### 1. 所需像素数

像素精度需留出安全余量，一般取检测精度的 1/2 ~ 1/4：

```
像素精度 = 精度要求 ÷ 安全系数
所需像素 = 视野 FOV ÷ 像素精度
```

再向上匹配到最接近的标准相机分辨率档位。

### 2. 镜头焦距

```
焦距 f = (靶面长边 × 工作距离) ÷ 视野 FOV
```

反算实际视野：

```
实际视野 = (靶面长边 × 工作距离) ÷ 选定焦距
```

远心镜头用放大倍率替代焦距：

```
倍率 = 靶面长边 ÷ 视野 FOV
```

### 3. 景深估算

弥散圆 δ 取 2 个像元，光圈 F5.6：

```
DOF = 2 · F · δ ÷ m²     其中 m = f / WD
```

## 选型示例

**场景**：视野 200mm、精度 0.1mm、工作距离 500mm、安全系数 3×

```
像素精度 = 0.1 ÷ 3 = 0.0333 mm/px
所需像素 = 200 ÷ 0.0333 = 6000 px
→ 匹配 4500 万像素（8192 × 5464）

理论焦距 = (17.6 × 500) ÷ 200 = 44 mm
→ 选 50mm

实际视野 = (17.6 × 500) ÷ 50 = 176 mm
实际像素精度 = 176 ÷ 8192 = 0.0215 mm/px
可检测精度 = 0.0215 × 3 = 0.064 mm  ✓ 余量充足
```

## 使用注意

工具给出的是**理论起点**，工程落地前还需校验：

- **景深**：高分辨率配置下景深可能只有几毫米，被测物有高度差时须缩小光圈或改用远心镜头
- **靶面覆盖**：镜头支持靶面必须 ≥ 相机靶面，否则画面四角出现暗角，直接损失有效视野
- **畸变率**：普通 FA 镜头有 0.1~1% 的畸变，精密测量需选低畸变型号或做标定
- **光照条件**：高像素意味着小像元，进光量下降，需配套更强的补光方案
- **镜头接口**：注意 C-mount / F-mount 与相机是否匹配

建议先用本工具确定规格范围，再向供应商索样实测。
